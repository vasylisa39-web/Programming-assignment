# Programming-assignment: Calculus GUI Calculator (Python)
Python-based interactive calculus calculator with a GUI that computes integrals, area between functions, and volume of revolution, with graphical visualisation using Matplotlib and Tkinter.

### **What the project does**
This project is a Python-based interactive calculator that performs key calculus operations such as definite integrals, area between two functions, and volume of revolution. It also provides graphical visualisation of functions and shaded regions to help users better understand mathematical concepts.

### **Why the project is useful**
The project is useful for students learning calculus because it combines numerical answers with visual graphs. It helps users understand abstract mathematical ideas in a more intuitive and visual way, rather than only working with formulas on paper.

### **How to Run**
1. Download or clone the project folder
2. Open the folder in Visual Studio Code
3. Open the main Python file (e.g. main.py)
4. Make sure Python is installed and required libraries are added (sympy, numpy, matplotlib)
5. Press the Run ▶ button in VS Code or right-click and select “Run Python File in Terminal”
6. The program window will open and you can start using the calculator

### **Note**
No terminal commands are required — the program can be run directly using the VS Code Run button.
From your program, these are external libraries (must install manually):
```
pip install sympy numpy matplotlib
```
*Install required dependencies using pip. Tkinter is included in standard Python installation.*
